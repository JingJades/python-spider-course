第三章：urllib库详解（1小时 · 3节课）

本章节目录：

本章目标：掌握 Python 标准库 urllib 的用法。它无需安装、开箱即用，了解它既能看懂老代码，也能在没有 pip 环境的机器上应急。实际项目中我们更推荐 requests，但 urllib 是理解 requests 底层原理的好教材。

第8课：urllib.request 模块——发送请求

8.1 urllib 与 requests 的关系

对比项 urllib requests
安装 Python 自带，无需安装 需要 pip 安装
易用性 代码较繁琐 简洁直观
功能 基础但完整 功能丰富、人性化
适用场景 极简脚本、无网管权限的机器 日常项目主力

8.2 最基本的 GET 请求

from urllib import request

response = request.urlopen('https://example.com')
html = response.read()            # 返回的是二进制 bytes
print(response.status)            # 状态码：200
print(html.decode('utf-8')[:100]) # 解码成字符串再打印

对比 requests 的三个关键差异：

  1. read() 返回的是二进制数据，需要自己 decode('utf-8') 解码；
  2. 状态码属性叫 status（requests 叫 status_code）；
  3. 没有 .json()、.text 这些贴心方法，都要手动处理。

8.3 携带参数与超时

from urllib import request, parse

# 查询参数需要用 parse.urlencode 编码后拼接到 URL
params = parse.urlencode({'keyword': 'python', 'page': 2})
url = f'https://httpbin.org/get?{params}'

response = request.urlopen(url, timeout=5)
print(response.read().decode('utf-8'))

8.4 用 Request 对象伪装请求头

urllib 不能在 urlopen 里直接传 headers，需要先构造 Request 对象：

from urllib import request

req = request.Request(
    'https://example.com',
    headers={
        'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) Chrome/120.0.0.0'
    }
)
response = request.urlopen(req, timeout=10)
print(response.read().decode('utf-8')[:100])

8.5 发送 POST 请求

POST 的数据必须编码成二进制，通过 data 参数传入：

from urllib import request, parse

data = parse.urlencode({'username': 'demo', 'password': '123456'}).encode('utf-8')
req = request.Request('https://httpbin.org/post', data=data, headers={
    'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) Chrome/120.0.0.0'
})
response = request.urlopen(req)
print(response.read().decode('utf-8'))

💡 可以看出：同样的事情 requests 两三行，urllib 要七八行。这也是为什么业界主流用 requests——但它们的底层逻辑完全一样，都是第一章讲的 HTTP 请求/响应模型。

📝 本课练习

  1. 用 urllib 请求 https://example.com，打印状态码和网页前 100 个字符。
  2. 改写第 8.4 节的代码：把 User-Agent 换成你自己浏览器的，验证 https://httpbin.org/headers 返回的结果。
  3. 思考：为什么 data 参数必须先 .encode('utf-8') 转成二进制？

第9课：urllib.parse 模块——URL 的处理工具箱

爬虫经常要「拆解 URL、拼接 URL、编码中文」，parse 模块就是干这些活的。

9.1 urlencode：字典 → 查询字符串

from urllib import parse

params = {'keyword': 'Python 爬虫', 'page': 1}
query = parse.urlencode(params)
print(query)   # keyword=Python+%E7%88%AC%E8%99%AB&page=1

url = 'https://www.example.com/search?' + query
print(url)

注意中文「爬虫」被编码成了 %E7%88%AC%E8%99%AB——这是 URL 的标准编码（URL 中不能直接放中文），编码是必需的，不是乱码。

9.2 quote / unquote：单独编码与解码

from urllib import parse

text = 'Python爬虫入门'
encoded = parse.quote(text)
print(encoded)                    # Python%E7%88%AC%E8%99%AB%E5%85%A5%E9%97%A8
print(parse.unquote(encoded))     # 还原：Python爬虫入门

9.3 urlparse：拆解 URL

from urllib import parse

url = 'https://www.example.com:443/news/list?page=3#content'
result = parse.urlparse(url)
print('协议:', result.scheme)      # https
print('域名:', result.netloc)      # www.example.com:443
print('路径:', result.path)        # /news/list
print('查询参数:', result.query)   # page=3

9.4 urljoin：拼接相对路径

网页里的链接经常是相对路径（如 /news/123.html 或 ../img/pic.jpg），抓取时必须转成完整 URL，urljoin 一行搞定：

from urllib import parse

base = 'https://www.example.com/news/index.html'
print(parse.urljoin(base, 'detail/123.html'))
# https://www.example.com/news/detail/123.html

print(parse.urljoin(base, '/about.html'))
# https://www.example.com/about.html

这个方法第六章实战会反复用到，务必掌握。

📝 本课练习

  1. 用 urlencode 构造一个搜索「数据分析 入门」的 URL。
  2. 用 urlparse 拆解 https://shop.example.com:8080/item/detail?id=9527&color=red，打印每个部分。
  3. 已知当前页面是 https://site.com/a/b/c.html，页面里有个链接 ../d/e.html，用 urljoin 算出它的完整地址。

第10课：error 异常处理模块

10.1 为什么异常处理是爬虫的「安全带」

爬虫要访问成百上千个网页，任何一次网络抖动、页面删除、服务器拒绝都可能让程序崩溃。没有异常处理的爬虫是半成品——半夜跑到第 997 页崩了，前面的数据全白爬。

10.2 两类核心异常

urllib 的 error 模块提供两个异常类，它们都和 requests 的异常一一对应：

异常 触发场景 举例
URLError 网络层面的问题（连不上服务器） 断网、域名不存在、超时
HTTPError 服务器有响应，但状态码是错误 404、403、500

HTTPError 是 URLError 的子类，所以捕获顺序必须先子后父。

10.3 标准异常处理模板

from urllib import request, error

url = 'https://example.com/not_exist_page'

req = request.Request(url, headers={
    'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) Chrome/120.0.0.0'
})

try:
    response = request.urlopen(req, timeout=5)
    html = response.read().decode('utf-8')
    print('抓取成功')
except error.HTTPError as e:
    print(f'HTTP错误: 状态码 {e.code}，原因 {e.reason}')
except error.URLError as e:
    print(f'网络错误: {e.reason}')
except Exception as e:
    print(f'其他错误: {e}')

10.4 实战技巧：失败重试机制

临时性失败（网络抖动）重试一次往往就好了，加上重试逻辑：

import time
from urllib import request, error

def fetch_with_retry(url, max_retry=3):
    """带重试机制的抓取函数"""
    req = request.Request(url, headers={
        'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) Chrome/120.0.0.0'
    })
    for attempt in range(1, max_retry + 1):
        try:
            response = request.urlopen(req, timeout=5)
            return response.read().decode('utf-8')
        except (error.HTTPError, error.URLError) as e:
            print(f'第 {attempt} 次尝试失败: {e}')
            if attempt < max_retry:
                time.sleep(2)   # 等2秒再重试，避免给服务器压力
    print('多次重试均失败，放弃该网址')
    return None

html = fetch_with_retry('https://example.com')
if html:
    print('成功获取', len(html), '个字符')

🕷️ 爬虫礼仪：重试间隔 time.sleep() 不是可有可无的——既提高成功率，也避免你的程序变成对目标网站的「轰炸」。

📝 本课练习

  1. 故意请求一个不存在的页面（如 https://example.com/404test），用标准模板捕获并打印 HTTPError 的状态码。
  2. 思考并回答：为什么必须先 except HTTPError 再 except URLError？调换顺序会怎样？
  3. 给 fetch_with_retry 增加一个功能：连续 3 次失败后，把失败的 URL 追加记录到 failed_urls.txt 文件里。

第三章小结：urllib vs requests 速查表

任务 urllib 写法 requests 写法
GET 请求 request.urlopen(url) requests.get(url)
获取文本 resp.read().decode('utf-8') resp.text
查询参数 parse.urlencode() 手动拼 params={}
请求头 构造 Request 对象 headers={} 直接传
POST data=...encode() data={}
状态码 resp.status resp.status_code
异常 error.HTTPError / URLError requests.exceptions.*

学习建议：日常写爬虫用 requests；读别人的老代码或面试时，urllib 的知识就派上用场了。
