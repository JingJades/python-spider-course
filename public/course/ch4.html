第11课：HTML基础与BeautifulSoup入门

11.1 快速看懂 HTML

网页源码由一层层嵌套的「标签」组成：

<html>
  <body>
    <div class="news-list">           <!-- 标签: div，属性: class="news-list" -->
      <a href="/news/1.html">标题一</a>  <!-- 标签: a，属性: href，文本: 标题一 -->
      <a href="/news/2.html">标题二</a>
    </div>
  </body>
</html>

三个必须记住的概念：

  • 标签（Tag）：尖括号包起来的部分，如 <a>、<div>、<p>
  • 属性（Attribute）：标签里的附加信息，如 href="/news/1.html"、class="news-list"
  • 文本（Text）：标签包裹的内容，如「标题一」

爬虫提取数据 = 找到目标标签 → 取出它的属性或文本。

11.2 创建 BeautifulSoup 对象

from bs4 import BeautifulSoup

html = '''
<div class="news-list">
  <a href="/news/1.html">标题一</a>
  <a href="/news/2.html">标题二</a>
</div>
'''

soup = BeautifulSoup(html, 'lxml')   # 第二个参数指定解析器
print(soup.prettify())               # 美化打印，查看解析后的结构

soup = BeautifulSoup(html, 'lxml') 是万事开头的那一行。没有 lxml 也可以用 Python 自带的 'html.parser'。

11.3 find 与 find_all：最常用的两个方法

from bs4 import BeautifulSoup

html = '''
<div class="news-list">
  <a href="/news/1.html">标题一</a>
  <a href="/news/2.html">标题二</a>
  <a href="/news/3.html">标题三</a>
</div>
'''
soup = BeautifulSoup(html, 'lxml')

# find：找【第一个】匹配的标签
first_a = soup.find('a')
print(first_a.get_text())        # 标题一
print(first_a['href'])           # /news/1.html（取属性像字典一样）

# find_all：找【所有】匹配的标签，返回列表
all_a = soup.find_all('a')
for a in all_a:
    print(a.get_text(), '→', a['href'])

运行结果：

标题一 → /news/1.html
标题二 → /news/2.html
标题三 → /news/3.html

11.4 按属性精确查找

页面上往往有很多 <a> 标签，需要靠属性缩小范围：

# 按 class 查找（注意是 class_ 带下划线，因为 class 是 Python 关键字）
news_div = soup.find('div', class_='news-list')

# 按 id 查找
title = soup.find('h1', id='main-title')

# 按任意属性查找
link = soup.find('a', attrs={'href': '/news/1.html'})

11.5 从标签里取数据的三种方式

假设 tag 是一个 <a href="/news/1.html"> 标题一 </a> 标签：

写法 结果 说明
tag.get_text() 标题一 提取文本（推荐）
tag['href'] /news/1.html 提取指定属性
tag.get('href', '无链接') /news/1.html 安全取属性，属性不存在时返回默认值不报错

第12课：CSS选择器——更优雅的定位方式

12.1 为什么需要 CSS 选择器

find 系列方法一次只能找一类标签，而 CSS 选择器可以像「路径导航」一样，一句话精确定位到嵌套多层的元素。它和浏览器开发者工具里看到的定位方式一致，是前端与爬虫通用的语言。

12.2 select 方法基础语法

from bs4 import BeautifulSoup

html = '''
<div id="content">
  <ul class="news">
    <li><a href="/1.html">新闻一</a></li>
    <li><a href="/2.html">新闻二</a></li>
    <li><a href="/3.html">新闻三</a></li>
  </ul>
  <p class="summary">共3条新闻</p>
</div>
'''
soup = BeautifulSoup(html, 'lxml')

# 1. 标签选择器：所有 a 标签
soup.select('a')

# 2. 类选择器：. 开头
soup.select('.summary')          # class="summary" 的元素

# 3. id 选择器：# 开头
soup.select('#content')          # id="content" 的元素

# 4. 后代选择器：空格分隔，一层层往下钻
links = soup.select('#content .news li a')
for a in links:
    print(a.get_text(), '→', a['href'])

# 5. 属性选择器
soup.select('a[href="/2.html"]') # href 恰好等于 /2.html 的 a 标签

12.3 select 与 select_one

  • soup.select('选择器') → 返回列表（哪怕只有一个结果）
  • soup.select_one('选择器') → 返回第一个匹配的元素（找不到返回 None）

12.4 实用技巧：从浏览器直接复制选择器

  1. 在网页上右键目标内容 → 检查，开发者工具会高亮对应 HTML；
  2. 在高亮的 HTML 上右键 → Copy → Copy selector；
  3. 粘贴到代码里：soup.select('粘贴的内容')。

浏览器自动复制的选择器有时过长（带一堆 nth-child），可以手动精简，保留关键的 class 层级即可。

12.5 CSS选择器 vs find 方法对照表

需求 find 写法 CSS选择器写法
按标签找 find_all('a') select('a')
按class找 find('div', class_='news') select('div.news')
按id找 find('div', id='content') select('#content')
多层嵌套 多次 find 链式调用 select('#content .news a')

两者可以混用，怎么顺手怎么来。

第13课：BeautifulSoup 综合实战——抓取新闻列表

把前两课组合起来，完成一个典型的真实任务：抓取一个列表页的所有标题和链接。

import requests
from bs4 import BeautifulSoup
from urllib import parse

def crawl_news_list(url):
    """抓取新闻列表页：标题 + 完整链接"""
    headers = {
        'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) Chrome/120.0.0.0'
    }
    try:
        response = requests.get(url, headers=headers, timeout=10)
        response.raise_for_status()
    except requests.exceptions.RequestException as e:
        print(f'请求失败: {e}')
        return []

    soup = BeautifulSoup(response.text, 'lxml')

    results = []
    # 假设新闻都在 class="news-item" 的 div 里（真实项目用F12确认选择器）
    for item in soup.select('.news-item'):
        title_tag = item.select_one('a')
        if title_tag:
            title = title_tag.get_text(strip=True)
            # 相对链接转绝对链接（第三章 urljoin 的用武之地）
            link = parse.urljoin(url, title_tag.get('href', ''))
            results.append({'title': title, 'link': link})
    return results

# 使用示例
news = crawl_news_list('https://example.com/news')
for i, n in enumerate(news, 1):
    print(f"{i}. {n['title']}  {n['link']}")

这段代码集中体现了前面所有章节的配合：

  • 第二章：headers 伪装、timeout、异常处理
  • 第三章：urljoin 处理相对链接
  • 第四章：select / select_one / get_text

get_text(strip=True) 中的 strip=True 能自动去掉文本两端的空白换行，是高频实用参数。

第14课：中文乱码处理

14.1 乱码是怎么产生的

网页内容在网络上传输时是二进制数据，浏览器/爬虫要用正确的「密码本」（字符编码）把它翻译成文字。中文网页常见的编码有 UTF-8 和 GBK/GB2312 两种。密码本用错了，「你好」就变成了「浣犲ソ」或「ÄãºÃ」。

14.2 requests 的智能解码与失效场景

requests 会自动猜测编码：

response = requests.get(url)
print(response.encoding)            # requests 猜测的编码
print(response.apparent_encoding)   # 根据内容特征分析的编码（更准）

当 response.text 出现乱码时，通常是猜错了，手动修正：

response = requests.get(url, headers=headers)
response.encoding = response.apparent_encoding   # 用更准的猜测结果
html = response.text   # 这次就是正常的中文了

或者直接指定已知编码：

response.encoding = 'utf-8'   # 或 'gbk'
html = response.text

14.3 终极方案：直接处理二进制

如果上面的方法都不行，还有万无一失的写法——拿二进制自己解码：

response = requests.get(url, headers=headers)
html = response.content.decode('utf-8', errors='ignore')
# errors='ignore'：遇到个别无法解码的字符直接丢弃，不报错

urllib 同理：

html = response.read().decode('utf-8', errors='ignore')

14.4 保存文件时的乱码预防

乱码不仅在「读取」时出现，写文件也要注意，始终显式指定 encoding='utf-8'：

with open('新闻标题.txt', 'w', encoding='utf-8') as f:
    f.write(title)

CSV 文件用 Excel 打开乱码是经典问题，解决办法是写入带 BOM 的 UTF-8：

import csv

with open('数据.csv', 'w', encoding='utf-8-sig', newline='') as f:
    writer = csv.writer(f)
    writer.writerow(['标题', '链接'])

记住 utf-8-sig 这个神奇编码，专治「Python 里看着好好的，Excel 打开全是乱码」。
