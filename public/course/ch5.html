第15课：正则表达式基础

15.1 什么时候用正则

对比感受两种工具的分工：

  • 「提取 <div class="news"> 里所有标题」→ 结构清晰，用 BeautifulSoup
  • 「从一大段文本里找出所有手机号、价格、日期」→ 没有标签结构，用 正则表达式

15.2 核心符号速查表

正则就是一套「符号暗号」，先记住最常用的：

符号 含义 例子
\d 一个数字 \d\d\d 匹配三位数
\w 字母/数字/下划线/中文 —
\s 空白字符（空格/换行） —
. 任意字符（除换行） —
* 前一个出现 0 次或多次 ab* 匹配 a、ab、abb
+ 前一个出现 1 次或多次 \d+ 匹配任意长度数字
? 前一个出现 0 次或 1 次 —
{n,m} 前一个出现 n 到 m 次 \d{11} 恰好 11 位数字
[] 字符集合 [0-9a-z]
() 分组（提取想要的部分） —
^ $ 开头 / 结尾 —

15.3 re 模块四大常用函数

import re

text = '订单A价格299元，订单B价格1280元，订单C价格59元'

# 1. findall：找出所有匹配，返回列表（最常用）
prices = re.findall(r'\d+', text)
print(prices)   # ['299', '1280', '59']

# 2. search：找第一个匹配，返回 Match 对象
m = re.search(r'\d+', text)
if m:
    print(m.group())   # 299

# 3. sub：替换
result = re.sub(r'\d+', '***', text)
print(result)   # 订单A价格***元，订单B价格***元，订单C价格***元

# 4. split：按模式切分
parts = re.split(r'，', text)
print(parts)    # ['订单A价格299元', '订单B价格1280元', '订单C价格59元']

💡 模式字符串前面加 r（如 r'\d+'）表示「原始字符串」，避免 \ 被 Python 提前转义，写正则永远带 r。

15.4 分组提取：只要想要的部分

() 分组是正则提取数据的精髓——模式负责「定位」，括号负责「取货」：

import re

text = '订单A价格299元，订单B价格1280元'

# 定位"价格...元"，但只提取括号里的数字
prices = re.findall(r'价格(\d+)元', text)
print(prices)   # ['299', '1280']

# 多组提取：一次抓多个字段
for name, price in re.findall(r'(订单\w+)价格(\d+)元', text):
    print(f'{name}: {price}元')

15.5 贪婪与非贪婪：爬虫高频坑

  • 贪婪（默认）：.* 尽可能多吃字符
  • 非贪婪：.*? 吃到满足条件就停
import re

html = '<p>第一段</p><p>第二段</p>'

print(re.findall(r'<p>.*</p>', html))
# ['<p>第一段</p><p>第二段</p>']   ← 贪婪：一口吞到最后的</p>

print(re.findall(r'<p>(.*?)</p>', html))
# ['第一段', '第二段']              ← 非贪婪：精准匹配每个段落

爬虫提取 HTML 内容时，绝大多数情况用 .*?（非贪婪），这是老司机的经验之谈。

第16课：正则实战——提取邮箱与URL

16.1 提取邮箱地址

import re

text = '''
联系我们：技术支持 support@example.com，
销售邮箱 sales_team@company.org.cn，
也可以写信给 admin@mail.example-site.com
'''

pattern = r'[\w.+-]+@[\w-]+(?:\.[\w-]+)+'
emails = re.findall(pattern, text)
for e in emails:
    print(e)

输出：

support@example.com
sales_team@company.org.cn
admin@mail.example-site.com

逐段拆解这个模式：

  • [\w.+-]+ —— @ 前面的用户名：字母数字下划线，还可能有点和加减号
  • @ —— 字面意义的 @
  • [\w-]+ —— 域名主体部分
  • (?:\.[\w-]+)+ —— 后缀部分：\. 是字面意义的点（. 在正则里是特殊符号，要 \ 转义），(?:...) 表示只分组不提取，+ 表示「点+一段字符」可重复多次，从而兼容 .org.cn 这种多级后缀和 mail.example-site.com 这种带横线的域名

16.2 提取 URL 链接

import re

text = '''
推荐教程 https://www.example.com/python 和
http://blog.demo.org/spider?page=2，
图片地址 https://cdn.example.com/img/logo.png
'''

urls = re.findall(r'https?://[\w./?=&%-]+', text)
for u in urls:
    print(u)
  • https? —— s? 表示 s 出现 0 或 1 次，同时兼容 http 和 https
  • [\w./?=&%-]+ —— URL 中可能出现的字符集合

16.3 实战组合：从网页源码中提取所有图片地址

import re
import requests
from urllib import parse

def extract_images(url):
    """提取网页中所有图片的完整地址"""
    headers = {
        'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) Chrome/120.0.0.0'
    }
    response = requests.get(url, headers=headers, timeout=10)
    response.encoding = response.apparent_encoding

    # 匹配 <img> 标签里的 src 属性
    img_srcs = re.findall(r'<img[^>]+src=["\'](.*?)["\']', response.text)

    # 相对路径转绝对路径 + 去重
    full_urls = []
    for src in img_srcs:
        full = parse.urljoin(url, src)
        if full not in full_urls:
            full_urls.append(full)
    return full_urls

for img in extract_images('https://example.com'):
    print(img)

16.4 其他常用正则模板（收藏备用）

import re

# 手机号（中国大陆11位）
phones = re.findall(r'1[3-9]\d{9}', text)

# 身份证号（18位）
id_cards = re.findall(r'\d{17}[\dXx]', text)

# 日期 2024-01-15 或 2024/01/15
dates = re.findall(r'\d{4}[-/]\d{1,2}[-/]\d{1,2}', text)

# 中文字符
chinese = re.findall(r'[一-龥]+', text)

# 价格 ¥299 或 ¥1280.50
prices = re.findall(r'¥\s*(\d+(?:\.\d+)?)', text)

16.5 BeautifulSoup 与正则的决策指南

场景 推荐工具
结构规范的 HTML 标签内容 BeautifulSoup
文本中零散的手机号/邮箱/日期 正则表达式
嵌套在 JS 代码、script 标签里的数据 正则表达式
先定位标签、再从文本里抠数字 两者组合
